Datastar plugin

data-prop

Bind reactive signals to DOM element properties, one property or several at once, with any Datastar expression.

GitHub npm Datastar docs

                Test 5
                
Select all checkboxes

                
An "all" checkbox toggles several checkboxes at once with the @setAll action. A single change handler on the parent handles every checkbox.

                
For this pattern, data-bind with data-effect is simpler than data-prop. The bulk update example in the Datastar docs shows a cleaner implementation.
